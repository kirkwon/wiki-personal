# MCP协议（Model Context Protocol）

MCP是AI Agent与外部工具和资源交互的标准协议，使AI助手能够安全、一致地访问各种数据源和工具。

## 核心价值

- 标准化AI Agent与外部系统的交互
- 支持本地和云端工具调用
- 降低AI Agent开发的复杂度
