# Via Negativa (Subtraction / What to Stop Doing)

**Also known as:** Negative Space, Subtraction, What to Stop Doing, Apophatic Method

A mental model that emphasizes defining things by what they are NOT rather than what they are. In strategy, it's the practice of achieving better outcomes by removing rather than adding.

## Core Idea

Most strategic problems are caused by addition — adding features, adding complexity, adding commitments. Via Negativa turns this around: what can you REMOVE that would make the system better?

## Applications

- **Strategy:** Instead of asking "what should we add?", ask "what should we stop doing?"
- **Design:** Remove features until the product breaks — then put the last one back
- **Decisions:** Eliminate options until one clearly remains
- **Habits:** Remove bad habits (negative space) rather than adding good ones
- **Writing:** Cut everything that doesn't serve the core thesis
- **Code:** Delete dead code before writing new code

## Connection to Strategic Framework

Via Negativa supports multiple steps:
- **Step 1 (WHY):** What happens if we DON'T do this? (Is the cost of inaction actually high?)
- **Step 5 (Invert):** What would REMOVING create better outcomes than adding?
- **Step 6 (Leverage):** What can we STOP doing to free resources for the 20%?

## Test

Before adding anything, ask: "If I remove this instead, does the system improve?"
