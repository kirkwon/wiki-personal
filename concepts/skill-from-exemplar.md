# Skill From Exemplar

> Reverse-engineer methodology from finished artifacts (books, papers, videos, code) that have NO teaching intent. Structure analysis → quality characteristic extraction → deduce production steps → generate skill. Use when you have great examples of work but no tutorial — Path B learning. Pairs with skill-from-masters for practice-first skill creation.

## Overview

- **When to Use** — - You have a great artifact (book, paper, blog post, code, video transcript) and want to turn it into a skill - The source has **no teaching intent** — it's a finished work, not a guide - You want to learn how something was *produced* by studying the product - You have 3+ exemplars of the same type and want to find the common methodology
- **When NOT to Use** — - The source is already a methodology document/tutorial (use `skill-creator` directly — that's Path A) - You need to find *who* the best practitioners are (use `skill-from-masters` first) - An existing skill already covers this (use `search-skill`)
- **The Two Paths** — | Path | Trigger | Process | |------|---------|---------| | **Path A: Methodology Document** | Source has teaching intent ("how to", numbered steps, guide) | Extract explicit methodology → validate → classify type → structure → generate | | **Path B: Exemplar (THIS SKILL)** | Source is a finished artifact (blog, PRD, code, paper) with no teaching intent | **Reverse-engineer**: structure analysis → quality extraction → deduce steps → generate |
