# Slide Organization Patterns

Structuring slide content into logical progressions that guide the audience through complex topics.

## Flow Patterns

### Sequential Progression
Organize slides into numbered parts that build on each other:
- Part 1: Foundation (concepts A, B, C)
- Part 2: Application (concepts D, E, F)
- Part 3: Synthesis (combines A-F)

### Thematic Groups
Organize by theme rather than sequence:
- Theme 1: Systems
- Theme 2: Habits
- Theme 3: Decisions

### Problem-Solution
Structure around a narrative arc:
- The Problem → describe the issue
- The Solution → present the approach
- Implementation → how to apply it

## Slide Types

- **Title Slide** — Main title with subtitle and key insight
- **Content Slide** — Section title with grid-based content
- **Comparison Slide** — Table format for side-by-side evaluation
- **Flow/Chain Slide** — Sequential steps with arrows

## Navigation Best Practices
- Add section footers for tracking (`<!-- _footer: 'NAME' -->`)
- Use clear headings that preview content
- Include summary slide at end
- Reference previous slides when building on concepts
- Each slide should answer one question
