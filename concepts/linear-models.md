# Linear Models

Simple models that assume linear relationships between variables — proportional changes in input produce proportional changes in output. Despite their simplicity, they deliver disproportionate insight when applied appropriately.

## Value

- Easy to understand and communicate
- Good first approximations
- Foundation for more complex models
- Useful for identifying key drivers
- Provide baseline expectations

## Limitations

- Cannot capture diminishing or increasing returns
- Miss threshold effects and non-linear dynamics
- Poor at modeling interactions between variables

## Connection to Model Selection

Linear models exemplify Page's principle that [[model-selection]] matters — starting with linear models and adding complexity only when needed is often the best approach.
