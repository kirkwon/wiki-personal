# Prism Discover

> Discover all possible analysis domains for an artifact. Finds obvious and non-obvious angles — architecture, security, but also marketing positioning, user psychology, regulatory implications, teaching value. Use before prism-scan or prism-full to explore what's worth investigating.

## Overview

- **When to Use** — Use first, when it is not yet clear what is worth analysing — "what should I even be looking at here", or before committing a `/prism-scan` or `/prism-full` run to one direction. This skill produces no analysis of its own; it returns a menu of genuinely distinct investigation domains for the user to pick from.
