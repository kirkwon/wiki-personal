# Writing Plans

> Write implementation plans: bite-sized tasks, paths, code.

## Overview

- **Overview** — Write comprehensive implementation plans assuming the implementer has zero context for the codebase and questionable taste. Document everything they need: which files to touch, complete code, testing commands, docs to check, how to verify. Give them bite-sized tasks. DRY. YAGNI. TDD. Frequent commits.
- **When to Use** — **Always use before:** - Implementing multi-step features - Breaking down complex requirements - Delegating to subagents via subagent-driven-development
- **Bite-Sized Task Granularity** — **Each task = 2-5 minutes of focused work.**
