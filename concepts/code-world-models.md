# Code World Models

A **Code World Model (CWM)** is an executable program (typically Python) that encodes the complete rules and dynamics of an environment — state transitions, legal actions, termination conditions, rewards, and observations. The term was introduced by [Lehrach et al. (2025)](https://doi.org/10.48550/arxiv.2510.04542) at Google DeepMind.

## Core Idea

Instead of using an LLM to *play* a game (direct move generation), use the LLM to *program* the game. The resulting executable model can then be searched by classical planning algorithms like [[concepts/monte-carlo-tree-search|Monte Carlo Tree Search (MCTS)]].^[extracted]

This creates a division of labor:
- **LLM → Translation** (natural language rules → executable code)
- **Classical planner → Search** (explore the formal game tree)

## Five Components of a CWM

| Component | Function | Purpose |
|-----------|----------|---------|
| State transitions | `apply(move, state) → state` | Simulate game progression |
| Legal moves | `legal_moves(state) → [moves]` | Constrain action space |
| Termination | `is_terminal(state) → bool` | Define game end |
| Reward | `reward(state) → float` | Evaluate outcomes |
| Observation | `observe(state, player) → obs` | Handle hidden information |

## Why It Works

The CWM pattern solves three fundamental problems of LLM game-playing:^[extracted]

1. **Verifiability** — executable code means correctness is decidable; illegal moves are structurally impossible
2. **Strategic depth** — MCTS explores thousands of positions; the LLM provides heuristics to prune
3. **Generalization** — the LLM translates *any* ruleset into code, even for games it's never seen

## Generalization Beyond Games

The CWM pattern applies to any domain where natural language rules can be formalized:^[inferred]

- **Financial modeling** — tax rules → simulation → portfolio optimization
- **Legal reasoning** — statutes → logic program → case evaluation
- **Operations research** — constraints → optimizer → scheduling
- **[[concepts/game-theory-and-strategic-analysis|Strategic decision-making]]** — competitive scenarios → game tree → equilibrium analysis

## Relation to AlphaZero

[[papers/alphazero|AlphaZero]] combined neural network heuristics with MCTS, but the game rules were manually coded. CWM extends this by making rule formalization autonomous — the LLM generates both the rules engine and the evaluation heuristics.^[inferred]
