# Call Option

Call Option είναι ένα διαφορικό σύμβολο (option) που δίνει το δικαίωμα, αλλά όχι την υποχρέωση, να αγοράσετε ένα πέρασμα σε ένα προκαθορισμένο strike price μέχρι την ημερομηνία expiration.

## Κέρδος
Ένα call option είναι κερδοφόρο όταν η τιμή του υποπτώματος είναι υψηλότερη από το strike price + premium που πληρώθηκε.

## Παράδειγμα
- Μετοχή σε $100
- Αγορά $105 call για $2 premium
- Σε expiration:
  - Αν μετοχή = $110 → Κέρδος = $110 - $105 - $2 = $3/συμβόλαιο
  - Αν μετοχή = $100 → Ζημιά = $2 premium

## Χρήσεις
- Bullish speculation
- Leveraged upside
- Income generation (covered calls)
