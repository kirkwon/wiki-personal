# Eisenhower Matrix

The classic urgency × importance 2×2. Quadrants: Do (urgent+important), Schedule (important, not urgent), Delegate (urgent, not important), Eliminate (neither). Use it to prioritize daily tasks.

## Application

Each morning, categorize today's tasks into the four quadrants. Focus on completing Quadrant 1 (Do) first, schedule Quadrant 2 (Schedule) for later, delegate Quadrant 3 if possible, and eliminate Quadrant 4.

## Personal Reflection

I tend to overestimate urgency and neglect important-but-not-urgent tasks like strategic planning and relationship building. Using this matrix helps me protect time for Quadrant 2 activities.
