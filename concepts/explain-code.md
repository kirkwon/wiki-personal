# Explain Code

> Generate clear, beginner-friendly code documentation and explanations with logic breakdowns, edge cases, and usage examples.

## Overview

- **Steps** — 1. Read full code snippet/file using `read_file` 2. Break down syntax, control flow, and dependencies 3. Explain purpose, inputs, outputs, and side effects 4. Highlight edge cases, error handling, and performance considerations 5. Output in Markdown with syntax-highlighted code blocks 6. Verify explanation matches actual code behavior (run tests if applicable)
- **Pitfalls** — - Using overly technical jargon without explanation - Missing context about external dependencies or APIs - Explaining *what* the code does without *why* it does it
- **Verification** — - Cross-check explanation against code execution (if possible) - Ensure all variables and functions are accounted for
