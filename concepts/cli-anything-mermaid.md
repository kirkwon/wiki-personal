# Cli Anything Mermaid

> Agent-native Mermaid Live Editor CLI — create, edit, render, and share Mermaid diagrams from the command line. 5 command groups (diagram, export, project, repl, session), SVG/PNG render, Mermaid Live share URLs. All support --json output.

## Overview

- **When to Use** — - Creating Mermaid diagrams programmatically (flowcharts, sequence, class, etc.) - Rendering Mermaid source to SVG/PNG for documentation - Generating shareable Mermaid Live edit/view URLs - Quick diagram iteration without browser
- **Installation** — Installed at `~/.hermes/hermes-agent/venv/bin/cli-anything-mermaid`.
- **Quick Reference** — **Global options:** `--json`, `--project FILE`, `--dry-run`
