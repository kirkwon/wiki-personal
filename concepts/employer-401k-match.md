# Employer 401(k) Match

The employer contribution to a 401(k) retirement plan, which Sethi describes as "free money" because it represents an immediate, guaranteed return on contributions.

## How It Works
- Employer matches a percentage of salary contributions (common: 50% match up to 6% of salary).
- Contributing 6% of a $50,000 salary = $3,000 out-of-pocket.
- Employer adds $1,500 as a match.
- This is a guaranteed 50% return on the contributed amount.

## Priority
Sethi ranks the 401(k) match as the first financial priority—before Roth IRA contributions, taxable investing, or debt payoff (unless debt interest exceeds 7%).

## Automation
Contributions are made through payroll deduction, making this fully automatic with no additional effort.
