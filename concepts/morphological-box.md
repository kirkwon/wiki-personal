# Morphological Box

Zwicky's method: break a problem into parameters, list options for each, then systematically combine. Generates novel solutions by forcing cross-category combinations.

## Application

For a challenging problem, identify its key dimensions (parameters). For each parameter, list all possible variations or values. Then systematically combine one option from each parameter to generate potential solutions, even seemingly odd ones.

## Personal Reflection

I've used this to break out of routine thinking when stuck on technical problems, leading to innovative approaches I wouldn't have considered through linear thinking alone.
