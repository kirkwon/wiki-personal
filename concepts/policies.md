# Policies

Policies is a conceptual tool or principle that helps understand and navigate complex situations. It provides a mental shortcut or framework for making sense of patterns and relationships in the world.^[raw/articles/Policies.md]

The model is grounded in Ray Dalio's work on big debt crises, where policy frameworks help decode how debt cycles and policy responses interact. Policies function as structured rules for navigating uncertainty, applicable across domains from macroeconomics to personal decision-making.^[raw/articles/Policies.md]

This mental model connects to existing decision-making frameworks and systematic approaches to complexity. It extends the wiki's mental model taxonomy by introducing "Policies" as a distinct tool alongside other universal models like Planning, Stillness, and Grit.^[raw/articles/Policies.md]

Confidence in this model is moderate (0.7), suggesting it is still being refined as a framework for application.^[raw/articles/Policies.md]
