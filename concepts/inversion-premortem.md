

# Inversion (Premortem Thinking)

**Also known as:** Premortem, Inversion Principle, Via Negativa in strategy

A mental model where you start by imagining failure and work backward to understand what causes it, rather than starting with success and working forward.

## Core Idea

Instead of asking "What do I need to do to succeed?", ask "What would cause this to fail spectacularly?" Then systematically eliminate those causes before they happen.

## The Premortem Technique

1. **Imagine the future:** "It's 6 months from now and this failed completely."
2. **Write the obituary:** Describe in detail what went wrong.
3. **Work backward:** Identify the root causes of each failure mode.
4. **Design safeguards:** Add verification gates for the most likely failure modes.

## Common Failure Modes

- Scope creep — didn't bound resources tightly enough
- Wrong assumptions — didn't verify early enough
- Dependency failure — external system broke or changed
- Over-engineering — built for scale before proving need
- Under-investing — cut corners that mattered
- Timing — too early (ecosystem not ready) or too late (market moved)
- Misaligned incentives — the thing that's good for the agent is bad for the outcome

## Connection to Strategic Framework

Inversion is **Step 5** in the Strategic Filter. Run the premortem before committing resources. The output should be 1-2 specific risks with concrete mitigation gates during execution.
