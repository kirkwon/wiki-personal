# Hook Model

The Hook Model is a four-phase framework for building habit-forming products. Each cycle through the loop increases the likelihood that a user will return and engage again without external prompting.

## The Four Phases

1. **Trigger** — The prompt that initiates the behavior. This can be external (notifications, ads, social cues) or internal (emotional associations like boredom, loneliness, or curiosity).
2. **Action** — The simplest behavior in anticipation of a reward. The Fogg Behavior Model states that behavior occurs when motivation, ability, and trigger converge.
3. **Variable Reward** — Unpredictable rewards that create anticipation and reinforce the behavior through dopaminergic mechanisms. Variability is key because predictable rewards satiate quickly.
4. **Investment** — Effort or data users put into the product (profile setup, content creation, streaks, preferences) that increases switching costs and the likelihood of return.

## Why It Works

Each pass through the loop makes the next pass more likely. User investment increases the product's value to the user, and internal triggers develop as the product becomes associated with specific emotional states. Over time, the product transitions from externally prompted to self-initiated use.
