## Overview

Jazz harmony extends traditional harmony with chord extensions (7ths, 9ths, 11ths, 13ths), altered tones, and complex progressions. Understanding jazz harmony is essential for improvisation and comping.

## Extended Chords

### Seventh Chords (The Foundation)

Jazz music is built on seventh chords:

| Chord Type | Notes in C | Symbol |
|------------|------------|--------|
| Major 7th | C - E - G - B | Cmaj7 |
| Dominant 7th | C - E - G - B♭ | C7 |
| Minor 7th | C - E♭ - G - B♭ | Cmin7 or C-7 |
| Minor 7♭5 | C - E♭ - G♭ - B♭ | Cmin7♭5 or Cø |
| Diminished 7th | C - E♭ - G♭ - B♭♭ | Cdim7 or C° |
| Minor Major 7th | C - E♭ - G - B | Cmin(maj7) or C-∆7 |

### Ninth Chords

Add the 9th (scale degree 9) to any 7th chord:

| Chord Type | Notes in C | Symbol |
|------------|------------|--------|
| Major 9th | C - E - G - B - D | Cmaj9 |
| Dominant 9th | C - E - G - B♭ - D | C9 |
| Minor 9th | C - E♭ - G - B♭ - D | Cmin9 or C-9 |
| Minor 9♭5 | C - E♭ - G♭ - B♭ - D | Cmin9♭5 |

### Eleventh Chords

Add the 11th (scale degree 11) to 9th chords. The 3rd is often omitted for cleaner voicings:

| Chord Type | Notes in C | Symbol |
|------------|------------|--------|
| Major 11th | C - E - G - B - D - F | Cmaj11 |
| Dominant 11th | C - E - G - B♭ - D - F | C11 |
| Minor 11th | C - E♭ - G - B♭ - D - F | Cmin11 or C-11 |

### Thirteenth Chords

Add the 13th (scale degree 13) to 11th chords. The 11th is often omitted:

| Chord Type | Notes in C | Symbol |
|------------|------------|--------|
| Major 13th | C - E - G - B - D - F - A | Cmaj13 |
| Dominant 13th | C - E - G - B♭ - D - F - A | C13 |
| Minor 13th | C - E♭ - G - B♭ - D - F - A | Cmin13 or C-13 |

## Altered Chords

Altered chords are dominant 7th chords with raised or lowered extensions. Used for tension and resolution.

### Altered Dominant 7th Chords

| Altered Tone | Notes in C | Symbol |
|--------------|------------|--------|
| 7th + ♯5 | C - E - G♯ - B♭ | C7♯5 or C+7 |
| 7th + ♭5 | C - E - G♭ - B♭ | C7♭5 |
| 7th + ♯9 | C - E - G - B♭ - D♯ | C7♯9 |
| 7th + ♭9 | C - E - G - B♭ - D♭ | C7♭9 |
| Altered 7th | C - E - G♯ - B♭ - D♯ - F♯ | C7alt |

### Altered Scale

The altered scale is used over altered dominant 7th chords. It's the 7th mode of melodic minor.

In C (for C7alt):
```
C - D♭ - E♭ - E - G♭ - A♭ - B♭ - C
```

## Common Jazz Progressions

### ii-V-I (The Foundation)

The most important progression in jazz. In C major:

| Roman Numeral | Chord | Function |
|---------------|-------|----------|
| ii | Dmin7 | Subdominant |
| V | G7 | Dominant |
| I | Cmaj7 | Tonic |

**Variations:**
- ii-V-I in minor: ii-7♭5 - V7alt - i-7
- iii-VI-ii-V: iii-7 - VI7 - ii-7 - V7 (turnaround)

### I-VI-ii-V (Turnaround)

| Roman Numeral | Chord | Function |
|---------------|-------|----------|
| I | Cmaj7 | Tonic |
| VI | A7 | Secondary dominant |
| ii | Dmin7 | Subdominant |
| V | G7 | Dominant |

### vi-ii-V-I

| Roman Numeral | Chord | Function |
|---------------|-------|----------|
| vi | Amin7 | Tonic substitute |
| ii | Dmin7 | Subdominant |
| V | G7 | Dominant |
| I | Cmaj7 | Tonic |

### Rhythm Changes

Based on George Gershwin's "I Got Rhythm":

| Measures | Chords |
|----------|--------|
| 1-4 | I6 - vi-7 - ii-7 - V7 |
| 5-6 | iii-7 - VI7 |
| 7-8 | ii-7 - V7 |
| 9-12 | I6 - IV6 | I7 - iii-7♭9 | vi7♭5 - ii7♭5 | V7♭9 |
| 13-16 | I7 - IV7 | iii-7♭9 - VI7♭9 | ii-7 - V7 |

## Secondary Dominants

A secondary dominant is a V7 chord that temporarily tonicizes a chord other than the I.

### Example in C Major
---

| Chord | Function | Target |
|-------|----------|--------|
| A7 | V7 of D | Dmin7 |
| B7 | V7 of E | Emin7 |
| C7 | V7 of F | Fmaj7 |
| D7 | V7 of G | G7 |
| E7 | V7 of F | Fmaj7 |
| F7 | V7 of B♭ | B♭maj7 |

## Tritone Substitution

Replace a V7 chord with a dominant 7th chord a tritone away. Both share the same 3rd and 7th (just swapped).

| Original | Tritone Sub | Why It Works |
|----------|-------------|--------------|
| G7 | D♭7 | Both have B and F (3rd and 7th) |
| C7 | F♯7 | Both have E and B♭ |
| D7 | A♭7 | Both have F♯ and C |

## Modal Interchange (Borrowed Chords)

Borrow chords from parallel major or minor keys.

### Common Borrowed Chords in C Major

| Chord | From | Function |
|-------|------|----------|
| Cmin7 | C minor | iv or ♭III |
| Fmin7 | C minor | iv |
| B♭maj7 | C minor | ♭VII |
| E♭maj7 | C minor | ♭VI |
| A♭maj7 | C minor | ♭VI (as ♭VI7 or ♭VI7♭5) |

## Voice Leading

Good voice leading moves each note as little as possible.

### Guidelines
1. **Keep common tones**: Notes shared between chords should stay on the same voice
2. **Stepwise motion**: Non-common tones move by step (2nd)
3. **Smooth transitions**: Avoid large leaps in individual voices
4. **Resolution**: Leading tones (7th of V7) resolve down by step

### Example: ii-V-I in C

```
Dmin7:     F - A - C - E
G7:        F - B - D - E  (F stays, A→B stepwise, C→D stepwise, E stays)
Cmaj7:     E - G - B - C  (F→E down stepwise, B→B stays, D→C down, E→C down)
```

## Practice Exercises

### ii-V-I Practice

1. **In all 12 keys**, starting with roots on the 6th string
2. **Using different voicings** (3-note, 4-note, shell voicings)
3. **Different positions** on the fretboard
4. **With extensions** (9ths, 11ths, 13ths)

### Tritone Substitution Practice

1. **Play V7 then its tritone sub** to hear the similarity
2. **Resolve both to I** to understand the tension
3. **Use in real songs** (Autumn Leaves, All the Things You Are)

### Altered Chord Practice

1. **Play dominant 7th** then each altered version
2. **Compare the sound** (more tension = more dissonance)
3. **Practice the altered scale** over each altered chord
4. **Use with tritone subs** for maximum tension

## Common Mistakes

| Mistake | How to Fix |
|---------|------------|
| Playing roots in every chord | Use rootless voicings, let bassist handle roots |
| Not resolving tensions properly | Guide tones (3rds and 7ths) should resolve logically |
| Using wrong extensions on minor chords | Use natural 9s, 11s on minor 7, ♭9, ♭13 on minor 7♭5 |
| Not hearing the tension | Slow down and listen to each chord change |
| Skipping ii-V-I drills | This is foundational, practice daily |
