# Evolving Agents in the Dark: Retrospective Harness Optimization via Self-Preference

**arXiv:** [2606.05922](https://arxiv.org/abs/2606.05922)
**Year:** 2026

## Abstract

Addresses the core problem of improving an agent harness (skills, tools, workflows) without ground-truth validation sets by using retrospective self-preference optimization.

## Relevance

Directly relevant to self-improving agents that refine their own tool-use and action spaces without supervision. Core reference for the Self-Harness meta-loop.
