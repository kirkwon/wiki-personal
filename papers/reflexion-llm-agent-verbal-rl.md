# Reflexion: Language Agents with Verbal Reinforcement Learning

**arXiv:** [2303.11366](https://arxiv.org/abs/2303.11366)
**Authors:** Noah Shinn, Federico Cassano, Edward Berman, Ashwin Gopinath, Karthik Narasimhan, Shunyu Yao
**Year:** 2023

## Abstract

LLM agents perform actions, receive feedback via memory, and use self-reflection to improve on subsequent attempts without gradient updates.

## Relevance

Definitive paper on critic/doer separation and verbal reinforcement loops. Core reference for Self-Harness architecture. The actor-critic separation is the direct academic foundation for Hermes critic/doer split.
