# AutoHarness: Improving LLM Agents by Synthesizing a Code Harness

**arXiv:** [2603.03329](https://arxiv.org/abs/2603.03329)
**Authors:** Xinghua Lou, Miguel Lazaro-Gredilla, Antoine Dedieu, et al.
**Year:** 2026

## Abstract

Automatically synthesizes a code harness that constrains LLM agents to valid actions within an environment, improving reliability and safety.

## Relevance

Automatic synthesis of code harnesses constraining agent actions to valid operations. The direct academic reference for Hermes' Self-Harness approach to agent harness improvement.
