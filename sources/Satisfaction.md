# Satisfaction Source

This source introduces "Satisfaction" as a mental model — a conceptual tool for navigating complexity through pattern recognition. It is cross-referenced with Barry Schwartz's work, particularly *Why We Work*, which examines motivation and meaning in work. The model is framed as universal in applicability with moderate confidence (0.7). See [[satisfaction]] for the mental model page.
