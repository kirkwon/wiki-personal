# Value

Value is a conceptual tool or principle that helps understand and navigate complex situations. It provides a mental shortcut or framework for making sense of patterns and relationships in the world.

This mental model is referenced in 1 source: Dan Ariely's Predictably Irrational, which demonstrates that value is subjective, context-driven, and predictably irrational through experiments on anchoring, decoy effects, and zero-price effects.
