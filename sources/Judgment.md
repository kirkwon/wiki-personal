# Judgment Source Summary

Judgment is a mental model introduced as a conceptual tool for navigating complex situations through pattern and relationship recognition. It functions as a mental shortcut rather than a formal decision-making framework, providing a perceptual lens for making sense of complexity.

## Key Points
- Defined as a universal mental model with confidence level 0.7
- Cross-referenced with Daniel Kahneman's *Thinking Fast and Slow*
- Draws on dual process theory and pattern recognition as core mechanisms
- Currently underdeveloped with limited independent validation beyond the Kahneman reference
