# Source: post-processing.md

The provided document is a comprehensive guide to post-processing in photography, covering everything from basic adjustments to advanced techniques and style development. Here's a structured summary and key takeaways to help you navigate the content effectively:

---

### **1. Core Post-Processing Techniques**
- **Basic Adjustments**:
  - **Exposure, Contrast, Highlights/Shadows**: Correct over/underexposure and enhance dynamic range.
  - **White Balance**: Use presets (e.g., Daylight, Cloudy) or custom settings for accurate color.
  - **HSL (Hue, Saturation, Luminance)**: Fine-tune specific colors (e.g., skin tones, skies).
  - **Tone Curve**: Adjust tonal range for contrast and mood (e.g., S-curve for dramatic effects).
  - **Lens Corrections**: Fix distortion, vignetting, and chromatic aberration.

- **Advanced Techniques**:
  - **HDR**: Combine multiple exposures for high dynamic range (ideal for landscapes).
  - **Panoramas**: Stitch photos for wide-angle views (use overlap and level camera).
  - **Focus Stacking**: Merge images for extended depth of field (macro/landscape photography).
  - **Compositing**: Blend elements from multiple shots (e.g., replace skies, add objects).

---

### **2. Developing Your Style**
- **Consistency**:
  - Use **presets** (saved adjustments) for a recognizable look.
  - Maintain consistent **contrast, color treatment, aspect ratios, and vignetting**.
- **Presets & Profiles**:
  - Create custom presets in Lightroom/Photoshop for quick application.
  - Experiment with different styles (e.g., film emulation, minimalist).

---

### **3. Common Mistakes to Avoid**
- **Over-editing**: Prioritize subtlety (e.g., avoid oversaturation or harsh clarity).
- **Histogram Clipping**: Watch for blown highlights or blocked shadows.
- **RAW vs. JPEG**: Shoot in RAW for greater flexibility.
- **Editing Bad Photos**: Start with well-composed shots.
- **Overusing Filters**: Use them as starting points, not the end goal.

---

### **4. Practice & Workflow**
- **Daily**:
  - Edit at least one photo per shoot.
  - Experiment with one adjustment (e.g., dehaze, split toning).
  - Create a preset.
- **Weekly**:
  - Edit a series for a consistent look.
  - Compare before/after edits.
  - Learn a new technique (e.g., HDR, panoramas).
- **Monthly**:
  - Curate a portfolio with consistent edits.
  - Mimic a photographer’s style.
  - Backup edited files to avoid loss.

---

### **5. Tools & Resources**
- **Software**:
  - **Adobe Lightroom/Photoshop** (essential for advanced edits).
  - **Free Alternatives**: GIMP, Darktable, or online tools like Pixlr.
- **Presets**:
  - **Paid**: Visual Supply Co., Mastin Labs, Pretty Presets.

- **Tutorials**:

  - Websites: Adobe tutorials, Phlearn, Fstoppers.
