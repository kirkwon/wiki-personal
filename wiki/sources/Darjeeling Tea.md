# Source: Darjeeling Tea.md

## Key Entities
- **大吉岭茶 (Darjeeling Tea)** — 茶类别，产自印度西孟加拉邦大吉岭地区的高海拔红茶，被称为"茶中香槟"。**核心实体**，本文件的主题。
- **中国杂交茶树 (Camellia sinensis var. sinensis)** — 大吉岭茶园种植的茶树品种。**中实体**，技术细节。
- **四大采摘季 (Flush System)** — First Flush、Second Flush、Monsoon Flush、Autumn Flush，不同季节的采摘形成独特风味。**核心概念**，贯穿全文。
- **各大茶园** — Castleton、Makaibari、Goomtee、Thurbo、Margaret's Hope、Seeyok、Teesta Valley、Sungma、Puttabong等。**中实体**，品质差异的来源。
- **地理标志保护 (Geographic Indication)** — 大吉岭茶获得GI保护。**中实体**，文化/法律意义。

## Key Concepts
- **Muscatel风味 (麝香葡萄风味)** — 大吉岭茶独有的果酒般风味特征，由喜马拉雅山地风土塑造。**核心概念**，全文反复强调的独特卖点。
- **Terroir (风土)** — 高海拔、凉爽气候、雾气、矿质土壤等环境影响茶叶品质。**核心概念**，解释风味差异的根源。
- **正典加工法 (Orthodox Processing)** — 12-18小时萎凋、手工揉捻、2-4小时氧化、低温烘焙的传统工艺。**重要概念**，与大吉岭品质相关。
- **采摘季系统 (Flush System)** — 四季采摘、不同天气条件产生不同风味。**重要概念**，大吉岭茶辨识度的核心。
- **茶品分级 (Leaf Grades)** — SFTGFOP1、FTGFOP1、GFOP等Orange Pekoe分级体系。**中概念**，市场定价依据。

## Main Arguments & Findings
- **核心主张**：大吉岭茶因独特风土和传统工艺，具有其他红茶无法复制的muscatel风味，品质随采摘季和茶园而异。
- **证据支持**：详细描述了海拔、气候、土壤、加工工艺、四大采摘季的风味差异、各大茶园的个性。信息综合性强，来源为行业常识与茶学知识。
- **证据强度**：中等。属于百科式综述，未引用具体科学研究，但内容专业且与现有茶学知识一致。可信度高，但缺乏一手数据。
