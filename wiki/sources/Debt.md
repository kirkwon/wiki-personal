# Debt

This source introduces "Debt" as a universal mental model—a conceptual tool for navigating complexity through pattern and relationship recognition. The primary reference is Ray Dalio's framework for understanding big debt crises, which provides a structured lens for analyzing how debt builds, peaks, and resolves across economies. The model is framed as applicable beyond pure finance, serving as a mental shortcut for making sense of patterns in the world.
