# Hooked - Nir Eyal

Nir Eyal's *Hooked* presents a four-phase framework for building habit-forming products: Trigger, Action, Variable Reward, and Investment. The book draws on behavioral psychology and case studies of successful products to explain how companies create self-reinforcing engagement loops.

The framework's core insight is that variable rewards and user investment create compounding return likelihood over time. Products succeed when they form internal triggers—emotional associations like boredom or curiosity—that drive self-initiated use without external prompting.

The book also addresses ethical questions: the line between empowering habits and exploitative manipulation, and the shared responsibility between designers and users. This connects to broader themes of decision quality, cognitive biases, and the ethics of influencing behavior.

Key concepts include the Fogg Behavior Model (motivation, ability, trigger convergence), habit testing (measuring whether users return without external triggers), and techniques for optimizing each hook component.
