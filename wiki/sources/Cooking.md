# Cooking as Mental Model

This source introduces cooking not as a culinary activity but as a universal mental model for navigating complex situations. Cooking provides a framework for making sense of patterns and relationships, functioning as a mental shortcut applicable across domains.

## Key Idea
Cooking serves as a conceptual tool for understanding and navigating complexity. By drawing analogies from cooking techniques and principles, one can develop mental shortcuts for broader problem-solving and pattern recognition.

## Source References
- Referenced from Timothy Ferriss's *The 4-Hour Chef*, which uses cooking as a teaching and learning metaphor.
