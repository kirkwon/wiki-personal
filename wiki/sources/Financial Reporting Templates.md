# Financial Reporting Templates

A suite of investment tracking and financial analysis tools for real estate, stocks, bonds, and portfolios. The templates encode best practices for monthly cash flow tracking, annual depreciation schedules, sensitivity analysis, RMD calculations, and tax-loss harvesting.

## Purpose
Investment performance tracking and financial analysis for real estate, stocks, bonds, and portfolio management using Excel and Google Sheets.

## Key Metrics and Formulas
- Cash on Cash Return: Net Cash Flow / Cash Investment
- Cap Rate: NOI / Property Value
- NOI: Gross Income - Operating Expenses
- IRR via cash flow ranges
- Break-Even Ratio: Operating Expenses / Gross Income
- Debt Coverage Ratio: NOI / Annual Debt Service

## Reporting Cadences
- Daily: Transaction entries and cash flow tracking
- Weekly: Portfolio performance updates
- Monthly: Comprehensive financial reporting
- Quarterly: Detailed analysis and portfolio rebalancing
- Annual: Tax preparation and long-term planning

## Template Components
- Single Property Analysis Template — cash flow, NOI, cap rate, cash-on-cash return
- Multi-Property Portfolio Template — aggregated portfolio metrics
- Stock Investment Tracker — ticker-level performance, dividend tracking, beta, P/E ratio
- Bond Investment Template — coupon, YTM, duration
- Retirement Savings Calculator and RMD Calculator
- Tax-Loss Harvesting Tracker and 1031 Exchange Analysis
- Sensitivity Analysis / What-If Scenarios
- Investment Property Acquisition
- Rental Property Tax Analysis with 1031 Exchange analysis

## Implementation Guidelines
Implementation guidelines cover Excel/Google Sheets setup, reporting cadence (daily transaction entry, weekly updates, monthly comprehensive reviews), and security considerations. The modular design philosophy emphasizes composable templates across asset classes for systematic financial reporting.
