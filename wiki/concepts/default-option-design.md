# Default Option Design

Leveraging inertia and status quo bias by setting the default option to the desired outcome. Because people tend to stick with pre-selected options, designing better defaults is one of the most powerful tools for shaping decisions.

## Key Principle

Most people do not actively change defaults. By choosing what is pre-selected, you can steer behavior at scale without requiring individual deliberation for every decision.

## Applications

- Organizational policies where the default enrollment option matters more than the available choices
- User experience design where the pre-selected feature determines majority behavior
- Retirement planning where automatic enrollment dramatically increases participation
- Any context where the cost of changing the default exceeds the perceived benefit of switching
