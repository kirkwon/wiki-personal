# Sharpe Ratio

Measures risk-adjusted return by dividing excess return over the risk-free rate by portfolio standard deviation.

$$\text{Sharpe Ratio} = \frac{\text{Return} - \text{Risk-free rate}}{\text{Standard deviation}}$$

## Usage

Tracked in the [[stock-and-bond-tracking]] portfolio performance template alongside beta, annualized return, and total portfolio value. Provides a standardized measure for comparing investment performance across different risk levels.

Used to compare portfolio return per unit of risk. A higher Sharpe Ratio indicates better return for the amount of risk taken.

## Benchmarks

- **>1.0**: Excellent
- **0.5–1.0**: Good
- **<0.5**: Negative return with risk weighting
