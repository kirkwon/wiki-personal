# Description (Kuvaileminen)

Description eli kuvaileminen on yksi kolmesta ydinmallista, jotka Ahrensin teos esittää maailmanavauksen työkaluina. Se viittaa tapaan, jolla ihmiset kuvailevat ja dokumentoivat todellisuutta.

Ydinväite: "Apply Description consistently for lasting results." Kuvaileminen on perustavanlaatuinen menetelmä, jolla totuus paljastuu systemaattisesti.

## Yhteys muihin käsitteisiin
- [[reality-mentaalimalli]] – Todellisuuden ymmärtäminen
- [[understanding-mentaalimalli]] – Tietoon perustuva ymmärrys
- [[world-disclosure]] – Maailmanavaus
- [[experimentation-mentaalimalli]] – Kokeellinen lähestymistapa

## Sovellus
Kuvaileminen on keskeinen kaikilla tieteenaloilla, taiteessa ja teknologiassa uuden tiedon dokumentoimisessa.
