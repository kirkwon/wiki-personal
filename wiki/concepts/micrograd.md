# micrograd

Micrograd is a conceptual library designed to facilitate the understanding and implementation of automatic differentiation (autograd) from first principles. It allows users to define computational graphs and then automatically calculate gradients for any variable within that graph, which is fundamental to training deep neural networks using gradient descent optimization. Unlike high-level frameworks like PyTorch or TensorFlow, micrograd focuses on making the underlying mechanics of derivative calculation explicit, serving as an educational tool for those learning machine learning theory.
