# Reference Class Forecasting

Reference class forecasting is a technique for improving prediction accuracy by comparing a current project or decision to similar past projects (the reference class) rather than relying on inside estimates. It directly mitigates the planning fallacy.

## How It Works

1. Identify a reference class of similar past projects
2. Calculate base rates (average outcomes) from the reference class
3. Use base rates as starting point for predictions
4. Adjust for known differences between current project and reference class

## Why It Works

The planning fallacy stems from overconfidence and inside-view optimism. Reference class forecasting forces an external perspective by anchoring expectations to historical data rather than personal estimates.
