# Wash Sale Rule

Wash Sale Rule είναι ένας φορολογικός περιορισμός που δεν επιτρέπει την εκφράζηση ζημιάς στο ίδιο security εντός ενός 30 ημερών παράθυρου. Εφαρμόζεται σε options στο ίδιο υποκείμενο.

## Key Points
- 30-day window: Δεν μπορείτε να εκφράσετε ζημιά στην ίδια εξάσκηση
- Εφαρμόζεται σε options στο ίδιο υποκείμενο
- Σχεδιάστε τις συναλλαγές σας αναλόγως
