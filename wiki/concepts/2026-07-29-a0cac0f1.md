## Andrew Ng + Anthropic Graph Engineering Synthesis (via @KanikaBK)

**Source**: Andrew Ng's DeepLearning.AI courses + Anthropic's Building Effective Agents
**Compiled by**: Kanika (@KanikaBK), July 2026
**PDF**: drive.google.com/file/d/1OdGtGSpD2KnR6vrqvFohj0n5gqhH03f5

### Central Thesis
GPT-3.5 + agentic workflow scores 95.1% on HumanEval vs GPT-4 zero-shot at 67.0%. **Architecture matters more than model.** A loop externalizes revision, a chain externalizes task order, a network externalizes role specialization, a graph externalizes shared state and relationships.

### Ng's 4 Patterns (maturity: robust → emerging)
1. **Reflection** (robust): LLM critiques own work against rubric, revises. 10-30% quality lift.
2. **Tool Use** (robust): LLM calls search/code/db. Grounds claims in reality.
3. **Planning** (emerging): LLM decomposes into steps, replans on failure. Key: preserve successful work across replans.
4. **Multi-Agent** (emerging): Role-specialized instances. Key: artifact contracts for handoffs.

### Anthropic's 5 Workflows
1. Prompt Chaining (fixed sequence)
2. Routing (classify → specialist)
3. Parallelization (sectioning or voting)
4. Orchestrator-Workers (dynamic delegation)
5. Evaluator-Optimizer (reflection as production workflow)

### Loop → Chain → Network → Graph Progression
- **Loop**: reflection in one context window. Breaks when context too large.
- **Chain**: fixed stages, programmatic gates between. Breaks on unexpected inputs.
- **Network**: multiple roles, orchestrator delegates. Breaks at context bottleneck (~5+ workers).
- **Graph**: shared persistent state. Workers read/write subgraph. Survives session flushes.

### Graph's 3 Roles in Multi-Agent
1. **Shared memory** for orchestrator-workers (replaces transcript bottleneck)
2. **Grounding layer** for evaluator-optimizer (claims checked against graph edges with provenance)
3. **Persistent world model** for loops (survives context flush)

### 5 Decision Rules
1. Start with cheapest pattern
2. Measure before promoting (< 5% failure → don't add complexity)
3. Match control to risk (high-stakes = predictable patterns)
4. Count tokens not agents (3 agents × 20k tokens = 1 agent × 60k tokens)
5. The graph earns itself when same entity queried by >1 agent or across sessions

### 7 Anti-Patterns
Everything-agent, echo chamber, infinite loop, phantom graph, conversational bottleneck, missing baseline, premature agent.

### Key Insights
- Fast inference is a capability multiplier (more iterations in same latency budget)
- Cheaper model + more iterations can beat expensive model once
- Graph should be designed from beginning for cross-session systems, not bolted on later
- 'Every important output can be traced to a task, plan, artifact, source, evaluator decision, and bounded execution record'
