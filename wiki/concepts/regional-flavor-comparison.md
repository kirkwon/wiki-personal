# 区域风味对比

中国不同菜系在辣度、味道强度、甜度、咸度、复杂度和烹饪热度上有显著差异。

## 风味对比表

| 特征 | 川菜 | 粤菜 | 湘菜 | 苏菜 |
|------|------|------|------|------|
| 辣度 | 非常高 | 低 | 非常高 | 低 |
| 味道强度 | 高 | 低 | 高 | 中等 |
| 甜度 | 低 | 低 | 低 | 高 |
| 咸度 | 中等 | 中等 | 高 | 中等 |
| 复杂度 | 高 | 中等 | 高 | 中等 |
| 烹饪热度 | 高 | 中等 | 高 | 中等 |

## 食材偏好对比

| 地区 | 核心食材 |
|------|---------|
| 川菜 | 花椒、辣椒、豆瓣酱 |
| 粤菜 | 新鲜海鲜、蚝油、酱油 |
| 鲁菜 | 海参、鲍鱼、浓厚高汤 |
| 苏菜 | 糖、轻调味、新鲜食材 |
| 湘菜 | 新鲜辣椒、腌制食品、烟熏肉 |
| 北京 | 羊肉、面食、葱 |

## 烹饪技法对比

| 地区 | 核心技法 |
|------|---------|
| 川菜 | 炒、干炒、炖 |
| 粤菜 | 蒸、炒、烤 |
| 鲁菜 | 炖、焖、烤 |
| 苏菜 | 炖、焖、蒸 |
| 北京 | 烤、炖 |
| 湘菜 | 炒、蒸、烟熏 |
