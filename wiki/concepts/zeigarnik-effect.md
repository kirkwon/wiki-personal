# Zeigarnik Effect

The tendency for incomplete tasks to remain active in memory, sometimes productively and sometimes not. Named after psychologist Bluma Zeigarnik, who observed that waiters remembered incomplete orders but forgot completed ones.

## Key Points
- Incomplete tasks create cognitive tension that demands resolution
- Can be leveraged for productivity (start tasks to create mental hooks)
- Can also cause anxiety and rumination if tasks pile up
- Connects to [[attention-residue]] — leftover mental focus from previous tasks
- Connects to [[procrastination]] — delaying tasks increases Zeigarnik burden

## Practical Use
Use the effect intentionally: starting a task creates mental engagement that can drive completion. But be mindful of accumulating incomplete tasks that create cognitive load.

## Guardrail
If Zeigarnik effect is causing anxiety, either complete the task or deliberately let it go rather than carrying it mentally.
