# Post-Processing

Post-processing is the act of editing photos after capture to enhance, correct, and style images. While photography is about capturing the moment, post-processing is about enhancing that capture to convey your vision. It is the editing phase after capture.

## Definition and Goals

**Definition**: Editing photos after capture to enhance, correct, and style images.

**Goals**:
- **Correct technical issues**: Exposure, white balance, color
- **Enhance visual impact**: Contrast, clarity, saturation
- **Create consistent style**: Develop personal aesthetic
- **Tell the story**: Guide viewer's eye, create mood

**Basic adjustments include**:
- **Cropping**: Improve composition
- **Exposure adjustment**: Brighten or darken
- **Contrast**: Enhance tonal range
- **White balance**: Correct color cast
- **Clarity/Dehaze**: Enhance details

## Philosophy

Great photos start with great captures. Post-processing enhances, doesn't fix bad photos. This is a core principle that distinguishes thoughtful editing from futile attempts to rescue poor captures.

### Film vs. Digital

**Film era**:
- Darkroom processing (developing, printing)
- Limited manipulation (mostly exposure, contrast)
- Fixed look (film type predetermined)

**Digital era**:
- Unlimited possibilities
- Non-destructive editing
- Each photographer's look

## Systematic Workflow

The typical post-processing workflow follows a structured sequence:

1. **Import**: Load photos into editing software, organize with keywords and collections
2. **Culling/Selection**: Rate photos (5 stars for portfolio-worthy, 1 star for poor), keep only the best 10-20%
3. **Global adjustments**: Apply to entire image — exposure, contrast, highlights, shadows, whites, blacks, clarity, vibrance, saturation, texture
4. **White Balance**: Correct color cast using presets or custom picker
5. **HSL (Hue, Saturation, Luminance)**: Adjust specific colors — skin tones, blue sky, green foliage
6. **Tone Curve**: Fine-tune tonal range; create S-curve for contrast by pulling up highlights and pulling down shadows
7. **Lens Corrections**: Fix distortion, vignette, chromatic aberration
8. **Effects**: Add vignette, grain, dehaze, split toning
9. **Crop and Straighten**: Improve composition, level horizons, change aspect ratios (3:2, 4:3, 16:9, 1:1, 2:3)
10. **Local Adjustments**: Use adjustment brush, gradient filter, radial filter, color range mask, luminance mask for targeted edits
11. **Export**: Save in appropriate format (JPEG, TIFF, PNG, PSD) with correct resolution and color space

## Advanced Techniques

### HDR (High Dynamic Range)
Combine multiple bracketed exposures (-2, 0, +2 EV) for extended dynamic range. Best for high contrast scenes like landscapes with bright sky and dark foreground.

### Panoramas
Stitch multiple overlapping photos (30-50% overlap) for wide views. Keep camera level with a tripod.

### Focus Stacking
Combine multiple photos at different focus distances for extended depth of field. Best for macro photography and landscapes.

### Compositing
Combine elements from multiple photos. Requires Photoshop. Examples: replace sky, add moon, combine people.

## Developing Your Style

Consistency in style is achieved through:
1. **Use presets**: Create starting points for different situations
2. **Consistent adjustments**: Similar contrast, color treatment across photos
3. **Aspect ratio**: Use the same ratio consistently
4. **Color palette**: Prefer certain color treatments
5. **Vignetting**: Use or avoid consistently

## Common Mistakes

| Mistake | How to Fix |
|---------|------------|
| Over-editing | Subtle is usually better |
| Oversaturation | Back off saturation |
| Too much clarity | Subtle enhancement, not harsh |
| Ignoring histogram | Watch for clipping (blown highlights, blocked shadows) |
| Not shooting RAW | RAW has more editing flexibility |
| Editing bad photos | Start with good captures |
| Overusing filters | Use filters tastefully, as starting points |

## Practice Exercises

**Daily**: Edit at least one photo from every shoot, experiment with one adjustment, create a preset.
**Weekly**: Edit a series with consistent look, compare before and after, learn a new technique.
**Monthly**: Curate portfolio, mimic a photographer's style, backup edited photos.
