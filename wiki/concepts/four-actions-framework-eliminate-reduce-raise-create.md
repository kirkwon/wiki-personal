# Four Actions Framework (ERRC Grid)

The **Four Actions Framework** — also known as the ERRC grid — is the core tool for reconstructing a company's value curve. It asks four questions that drive value innovation:

1. **Eliminate** — Which factors that the industry takes for granted should be eliminated?
2. **Reduce** — Which factors should be reduced well below the industry standard?
3. **Raise** — Which factors should be raised well above the industry standard?
4. **Create** — Which factors should be created that the industry has never offered?

By systematically applying these four actions, companies can break away from competitive convergence and create new value curves that make competition irrelevant. This framework operationalizes [[value-innovation]] and feeds into the [[strategy-canvas]] analysis.

The ERRC grid can become formulaic if applied without genuine insight — tension exists with [[heuristic-problem-solving]] concerns about oversimplification, and [[probability-and-judgment-under-uncertainty]] cautions against overconfidence in market creation claims.
