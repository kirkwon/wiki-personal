# Time Signatures and Note Values

## Time Signatures

Time signatures indicate how many beats per measure and what note value gets one beat.

| Time Signature | Beats per Measure | Note Value |
|----------------|-------------------|-------------|
| 4/4 | 4 | Quarter note |
| 3/4 | 3 | Quarter note (waltz) |
| 2/4 | 2 | Quarter note (march) |
| 6/8 | 2 (compound) | Dotted quarter note |

## Note Values

| Symbol | Name | Duration |
|--------|------|----------|
| 𝅝 | Whole note | 4 beats in 4/4 |
| 𝅗𝅥 | Half note | 2 beats in 4/4 |
| 𝅘𝅥𝅮 | Quarter note | 1 beat in 4/4 |
| 𝅘𝅥𝅯 | Eighth note | 1/2 beat in 4/4 |
| 𝅘𝅥𝅰 | Sixteenth note | 1/4 beat in 4/4 |

Rests indicate silence and correspond to each note value. Understanding time signatures and note values is core to [[rhythm-and-meter]] and overall music theory fundamentals.
