# Claude Code

Claude Code是Anthropic推出的AI编程助手工具，能够执行代码、调用工具、进行语音交互，并支持Agent技能链式调用。

## 主要功能

- 代码编写与执行
- 工具调用与MCP协议集成
- 语音模式
- 定时任务调度
- 与Karpathy的AutoResearch框架结合
