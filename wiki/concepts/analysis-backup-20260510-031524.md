## Main Topic
Automated knowledge ingestion pipeline that processes data from multiple sources (Evernote, Pinterest, Obsidian, Apple Notes) into a unified format, enriches with wisdom extraction, imports into GBrain knowledge graph, and enables semantic search.

## Learning Objectives
After viewing this infographic, the viewer should understand:
1. The end-to-end pipeline architecture for knowledge ingestion
2. The classification of data sources as historical vs ongoing
3. The technical components and scripts involved in each stage
4. The scheduling and monitoring mechanisms

## Key Data Points (Verbatim)
- Sources: Evernote (historical), Pinterest (historical), Obsidian/Logseq exports (historical), Apple Notes (ongoing)
- Directory structure: ~/data-ingestion/ with sources/, staging/, scripts/, logs/, config.yaml
- Pipeline steps: detect changes → convert → optional extract-wisdom → update index → record hash → gbrain import --no-embed → gbrain embed --stale
- Schedule: Ongoing via cron every 15-30 minutes; One-time manual after placing export in sources/
- Cost: extract-wisdom (~0.5-1s/file via local Ollama phi3)
- Monitoring: Log each stage, alert on embed backlog, periodic gbrain doctor --json
- Technical notes: GBrain put uses redirect `<` not --content; Orphan linker v9 60% hit rate; Synthesize needs dream.synthesize.enabled true AND dream.synthesize.session_corpus_dir set
