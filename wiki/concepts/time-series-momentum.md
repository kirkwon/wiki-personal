# Time-Series Momentum

Time-series momentum compares an asset to its own past performance. If an asset has risen over a look-back period, it is bought; if it has fallen, it is avoided.

## Example

- S&P 500: +15% in past 12 months → Buy
- If S&P 500 had returned -10% → Buy Treasuries instead

This differs from cross-sectional momentum, which ranks assets against each other within the same universe.

## Connection to Trend Following

Time-series momentum with longer look-back periods (e.g., 200-day moving average) is closely related to [[trend-following]] strategies used for asset allocation between stocks and bonds/cash.
