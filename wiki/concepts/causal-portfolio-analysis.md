# Causal Portfolio Analysis

This advanced domain combines financial modeling with causal inference techniques to determine the true impact of investments and market factors. Unlike standard correlation analysis, which only measures association, this method aims to isolate cause-and-effect relationships (e.g., "Did increasing spending on X *cause* a rise in Y?").
