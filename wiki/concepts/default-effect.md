# Default Effect

The tendency to choose default options and how this influences behavior. When an option is pre-selected, people disproportionately choose it regardless of whether it is optimal.

## Key Points
- Defaults have enormous power over decisions
- Connects to [[choice-overload]] — too many options causing paralysis
- Often exploited in choice architecture (organ donation opt-out vs opt-in)
- Related to status quo bias

## Practical Guardrail
When a default is set, actively ask whether it was chosen deliberately or is merely the default. Re-evaluate options independently of their default status.
