# Depreciation Recapture Deferral

**Depreciation recapture** at 25% federal is deferred through a 1031 exchange. The recapture tax is not eliminated but deferred, allowing continuous deferral through multiple exchanges. Eventually a taxable event occurs when the investor exits the exchange cycle.

## Key Points
- Depreciation Recapture Rate: 25% federal
- State treatment varies by state
- 1031 exchange defers depreciation recapture tax
- Long-term benefit comes from continuous deferral through multiple exchanges
- Eventually must sell or face depreciation recapture when exiting the exchange cycle
