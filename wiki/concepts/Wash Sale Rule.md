# Wash Sale Rule

The wash sale rule prevents claiming a loss on the same security within a 30-day window. It applies to options on the same underlying asset.

## Σημασία
- 30 ημέρες παράθυρο: Δεν μπορείτε να δέχεστε απώλεια στο ίδιο security
- Εφαρμόζεται σε διαφορές στο ίδιο υποκείμενο
- Σχεδιάστε τις συναλλαγές σας κατάλληλα
