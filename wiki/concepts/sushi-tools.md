# Sushi Tools (寿司道具)

## 必須道具

| 道具 | 用途 |
|------|------|
| **Hangiri** - 木の桶 | 寿司米の調理 |
| **Shamoji** - 米切り | 米を混ぜる |
| **Yanagiba** - 刺身包丁 | 生魚をスライス |
| **Makisu** - 竹巻き簾 | 巻き寿司を作る |
| **Nori** - 干し海苔 | 巻き寿司の皮 |

## 包丁の選び方

- **Yanagiba** - 刺身、握り寿司用（長く、片刃）
- **Deba** - 丸魚を切る
- **Usuba** - 野菜の下処理
- **Santoku** - 万能包丁

## カスタマーズティップ

- 包丁は使用前に研ぐ
- 米は室温で提供する
- 握り寿司は魚の側だけに軽く醤油をつける
