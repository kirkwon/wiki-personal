# Sashimi Fish Guide (刺身用魚のガイド)

## 魚の種類と季節

| 魚 | 季節 | 特徴 |
|------|------|------|
| マグロ (Maguro) | 通年 | しっかり、脂肪のレベルが異なる |
| サーモン (Sake) | 通年 | 丰かな脂 |
| ハマチ (Yellowtail) | 春、秋 | バターのような、やわらかい |
| イカ (Squid) | 通年 | コリのコリ、甘い |
| タコ (Octopus) | 通年 | コリのコリ、ナッツのような |
| サバ (Mackerel) | 秋 | 丰かな油 |
| タイ (Sea bream) | 春、秋 | デリケート、甘い |
| ヒラメ (Flounder) | 冬 | デリケート、繊細 |
| アジ (Horse mackerel) | 夏 | 丰かな油 |
| イクラ (Salmon roe) | 秋 | 塩辛く、ぷちっと |

## 他のトッピング

- エビ (Ebi) - 煮たエビ
- ウナギ (Unagi) - ソースで焼いたうなぎ
- タマゴ (Tamago) - 甘い卵オムレツ
- ウニ (Uni) - ムニカン

## 調理のポイント

- とても鋭い包丁（Yanagiba）を使用
- 繊維に逆らって切断
- 30-45°の角度でカット
- 提供直前にスライス
