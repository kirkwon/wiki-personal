# Getting Things Done (GTD)

Getting Things Done is a comprehensive personal productivity methodology developed by David Allen. It provides a systematic framework for managing all commitments, ideas, and tasks by moving them out of the mind and into trusted external systems. The core process involves five stages: Capture (collecting everything), Clarify (defining action items), Organize (placing items in appropriate locations), Reflect (reviewing systems regularly), and Engage (executing actions). GTD aims to reduce cognitive load by ensuring nothing falls through the cracks, allowing users to achieve a state of "mind like water."
