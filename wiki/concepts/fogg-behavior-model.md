# Fogg Behavior Model

The Fogg Behavior Model (FBM) states that behavior occurs when three elements converge simultaneously: motivation, ability, and trigger.

## The Three Elements

1. **Motivation** — The user must want to perform the behavior
2. **Ability** — The user must be able to perform the behavior (simplicity)
3. **Trigger** — A prompt must be present to initiate the behavior

## Application in Hook Model

The Fogg Behavior Model is used in the Hook Model's Action phase to explain why users complete the intended behavior. Even with a trigger present, behavior will not occur if motivation is too low or ability is too high. This connects to [[hook-model]] and [[variable-reward-design]] — rewards increase motivation, while simplifying actions reduces the ability barrier.

## Simplicity as a Lever

The model emphasizes that increasing ability (making actions simpler) is often more effective than increasing motivation. This principle guides the "Designing Action" phase of the Hook Model.
