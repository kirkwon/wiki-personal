# Value as a Mental Model

Value is a conceptual tool that helps understand and navigate complex situations. It provides a mental shortcut or framework for making sense of patterns and relationships in the world. Rather than treating value as an objective measurement, this model recognizes that humans construct and perceive value in ways that are context-dependent and often irrational.

## Core Ideas

- Value is subjective and constructed through context rather than inherent in objects or outcomes.
- Perceived value is shaped by anchoring, decoy effects, and zero-price effects, as demonstrated by Dan Ariely in Predictably Irrational.
- Understanding how value is constructed helps navigate decisions where context manipulation can distort perception.

## Connections to Existing Concepts

Value connects directly to [[framing-effects]], which describes how decision framing impacts perceptions and choices. It extends [[prospect-theory]] by adding behavioral economics insights about constructed value. The [[cognitive-biases-library]] provides additional context for how context-dependent value perception leads to systematic errors.

## Open Questions

How does the "value" mental model differ from [[framing-effects]] or [[prospect-theory]]? The universal applicability claim needs clarification, since Ariely's work specifically highlights domains where value perception is systematically biased rather than reliable.
