# Machine Learning

Machine learning (ML) is a field of artificial intelligence that enables systems to learn from data without being explicitly programmed. Instead of following rigid rules, ML algorithms build statistical models that recognize patterns and make predictions based on input data—a core function of modern statistics. Techniques range from supervised learning (using labeled examples) to unsupervised learning (finding hidden structures), allowing machines to improve performance over time. This methodology drives many contemporary applications, including image recognition and natural language processing.
