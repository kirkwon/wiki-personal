# Like-Kind Requirement

The like-kind requirement for 1031 exchanges is straightforward: any real property can be exchanged for any other real property.

## Key Principles
- **Real Estate for Real Estate**: Any type of real property can be exchanged for any other type of real property
- **Geographic Flexibility**: Properties can be in different states
- **Value Flexibility**: Can exchange a single property for multiple properties
- **Debt Relief**: No boot from debt relief unless fully replaced

This flexibility is a key advantage of the 1031 exchange strategy, enabling investors to diversify, upgrade, or reposition their real estate holdings without triggering immediate capital gains taxes.
