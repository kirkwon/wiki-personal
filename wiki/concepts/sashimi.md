# 刺身（Sashimi）

刺身は生魚のみの料理。酢飯なしで新鮮な魚をそのまま食べる。

## 魚の種類と旬

| 魚 | 旬 | 特徴 |
|------|------|------|
| マグロ | 通年 | 硬く、脂のレベルが異なる |
| 鮭 | 通年 | 油っこく、脂が多い |
| 鰤 | 春・秋 | バターのような滑らかさ |
| イカ | 通年 | 弾力があり甘い |
| タコ | 通年 | 弾力がありナッツ風 |
| 鯖 | 秋 | 油っこく濃い |
| 鯉 | 春・秋 | 繊細で甘い |
| ヒラメ | 冬 | 繊細で上品 |
| アジ | 夏 | 油っこく濃い |
| イクラ | 秋 | 塩気がありパップリ |

## 下ごしらえ
- やんぎ刃（長く、片刃）で切る
- 穀物に逆らって切る
- 30-45度の角度で切る
- 食べる直前に切る

## 鮮度の指標
- 目が輝いていること
- 鰭が赤いこと
- 身が硬いこと
- 異臭がないこと
