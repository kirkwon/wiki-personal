# Thiel mental model

The Thiel mental model is a conceptual tool or principle that helps understand and navigate complex situations. It provides a mental shortcut or framework for making sense of patterns and relationships in the world.

## Core Principles
- **Zero to One thinking**: Creating something entirely new (0→1) rather than copying existing things (1→n)
- **Contrarianism**: Essential for finding overlooked opportunities and undiscovered truths
- **Monopoly vs competition**: Monopolies drive progress; competition is for losers
- **Secrets**: Focus on undiscovered truths about the world that others have overlooked
- **Technology and globalization**: Frameworks for understanding how innovation reshapes value creation

## Applicability
Universal across domains. Functions as a shortcut for pattern recognition in complex situations.
