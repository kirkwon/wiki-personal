# Symmetry and Patterns

Symmetry and patterns are composition techniques that use mirrored elements and repeating visual elements to create balance, harmony, and visual interest.

## Symmetry

Mirrored elements create a sense of balance and order.

- **Vertical symmetry**: Reflections in water, symmetrical architecture
- **Horizontal symmetry**: Balanced top and bottom
- **Radial symmetry**: From a center point (circles, spirals)

To use symmetry, find symmetrical scenes like architecture or reflections, center the frame, and carefully align the camera using a grid.

## Patterns

Repeating elements can fill the frame as the subject. Find repeating elements like windows, bricks, leaves, or textures. Breaking the pattern with one different element creates focal interest.
