# よくある失敗と修正法

| 失敗 | 修正法 |
|------|--------|
| 米が温すぎるまたは冷たすぎる | 室温で出す |
| 米の味付けが過剰 | 次回、酢を少なくする |
| 握り寿司を醤油に浸しすぎ | 軽く、魚の側だけ浸す |
| 包丁が鈍い | 使用前に研ぐ |
| 寿司グレード魚を使っていない | 信頼できる場所で購入 |
| 酢飯が Stickinessすぎる | より丁寧に米を研ぐ |
