
# Habit Testing

Habit testing is a method for determining whether a product has become truly habit-forming. The core test is simple: do users return without an external trigger?

## The Test

- Remove all external triggers (notifications, emails, ads)
- Measure whether users still engage with the product
- If they do, the product has formed an internal trigger and a genuine habit
- If they don't, the product relies on external prompts and has not yet habituated

## Metrics

Habit testing involves tracking:
- Trigger-to-action conversion rates
- Variable reward effectiveness
- User investment levels and return rates
- Engagement frequency patterns
- Habit formation rates (users who return after initial use)

## Purpose

Habit testing validates whether the [[hook-model]] loop is working as intended. It separates true habit formation from mere engagement driven by external prompts. This connects to [[internal-triggers]] — a successful habit test indicates that internal triggers have been established.
