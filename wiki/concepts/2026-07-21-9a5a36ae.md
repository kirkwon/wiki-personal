# Better Ways to Build Self-Improving AI Agents

**Author:** Yohei Nakajima (Untapped Capital)
**Source:** https://yoheinakajima.com/better-ways-to-build-self-improving-ai-agents/
**Date:** December 5, 2025

## Summary

Synthesizes NeurIPS 2025 and prior work on self-improving AI agents. Identifies six main mechanisms:
1. Self-reflection and in-loop feedback (prompt-level improvement without changing weights)
2. Self-generated data and curricula (agents create the data they learn from)
3. Self-adapting models (agents that fine-tune or edit themselves)
4. Self-improving code agents (agents that modify their own code, policies, or architecture)
5. Embodied self-improvement (agents learning by acting in environments)
6. Verification, safety, and control (keeping self-improvement from going off the rails)

## Key Claims

Reflexion (Shinn et al., 2023) demonstrates that verbal RL via natural-language self-critique bumped GPT-4 HumanEval pass@1 to ~91%. However, improvements are ephemeral unless reflections are persisted and reused. The model can hallucinate bad reflections and reinforce them.

Self-Refine (Madaan et al., 2023) uses a generate → critique → revise pattern. This works well for text and code generation, often improving quality over single-shot outputs.

RISE - Recursive Introspection (Qu et al., 2024) fine-tunes models on multi-turn traces where an initial answer is wrong, feedback arrives, and a corrected answer follows. After training, the model can simulate this introspection loop internally at inference time. However, it needs curated mistake-fix traces and may be domain-specific.

STaR - Self-Taught Reasoner (Zelikman et al., 2022) uses self-generated reasoning traces: the model produces solutions, filters for correct ones, then fine-tunes on these reasoning paths. Over iterations, small models become substantially stronger reasoners.

We find that reflection-style loops are easy to bolt onto existing agents but don't change the underlying model. We argue these are runtime optimization layers, not long-term learning. Learning to improve can itself be a training objective: you train for good corrections and good reasoning traces, not just good answers. This blurs the line between agent loop and model training.

## Limitations

The survey notes that current self-improvement approaches face several limitations: ephemeral gains without weight updates, risk of reinforcing hallucinated reflections, domain-specificity of self-correction training, and the fundamental challenge that reward hacking can corrupt the self-improvement signal.
