# Automated Savings

A financial behavior design principle: removing willpower from the equation by automating savings transfers and bill payments. The Index Card Rules emphasize treating savings like a bill you must pay, not an optional afterthought.

## Key Practices

- **Automate transfers** on payday — save before spending
- **Start small** — begin with 1% of income, increase by 1% each month
- **Save in tax-advantaged accounts first** — emergency fund → 401(k) match → Roth IRA → remaining 401(k) → taxable
- **Track spending weekly** — awareness drives better habits

## Behavioral Rationale

Automating savings leverages the same behavior-design principles as [[fizzgogg-behavior-model]] — ensuring the trigger (payday) converges with the ability (automatic transfer) and motivation (building wealth) to create consistent behavior without relying on willpower.
