# Tools Mental Model

The Tools Mental Model describes how an agent or system learns to treat external software and APIs as extensions of its own cognitive abilities. Rather than simply calling a function, the model involves understanding *when* and *why* a tool is necessary for task completion. This framework allows large language models (LLMs) to reason about their limitations and proactively integrate specialized computational resources into complex workflows.
