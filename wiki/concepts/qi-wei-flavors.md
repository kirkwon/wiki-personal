# 七味

川菜以七种不同的风味轮廓（七味）闻名，超越了对单一辣味的认知。四川菜的风味体系不仅限于麻辣，而是由七种风味类型组成，这是理解四川菜复杂味觉层次的关键概念。

## 七种风味

| 风味 | 描述 | 代表菜品 |
|------|------|---------|
| **麻辣** | 麻与辣的结合 | 麻婆豆腐、火锅 |
| **鱼香** | 蒜、姜、葱、糖、醋的组合 | 鱼香茄子 |
| **红烧** | 酱油与糖的平衡 | 红烧肉 |
| **姜毒（亦称姜督）** | 强姜味 | 姜鱼、姜汁鱼 |
| **咸鲜（亦称咸酥）** | 咸味与鲜味的深度 | 回锅肉 |
| **清淡** | 轻淡温和 | 姜蒸鱼、姜汁蒸鱼 |
| **酸辣** | 酸与辣的刺激 | 酸辣鱼、酸辣鱼汤 |

这七种风味构成了四川菜菜单规划的基础，确保每餐都能在麻、辣、香、咸之间取得平衡。这一分类体现了川菜风味的多样性，是理解川菜的核心框架。

## 与麻辣味的关系

七味体系中，麻辣味是最具标志性的，但四川菜的高明之处在于能够在这七种风味之间灵活切换，创造出丰富的味觉体验。即使是看似清淡的菜品，也与麻辣味形成对比和衬托。
