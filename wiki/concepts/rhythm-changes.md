# Rhythm Changes

Rhythm changes er en 16-takt jazzprogresjon basert på George Gershwins "I Got Rhythm". Det er en av de mest spilte progresjonene i jazz og brukes som basis for mange improvisasjoner, komposisjoner og standardlåter.

## Progresjonsstruktur

| Takt | Akkorder |
|------|----------|
| 1-4 | I6 - vi-7 - ii-7 - V7 |
| 5-6 | iii-7 - VI7 |
| 7-8 | ii-7 - V7 |
| 9-12 | I6 - IV6 \| I7 - iii-7♭9 \| vi7♭5 - ii7♭5 \| V7♭9 |
| 13-16 | I7 - IV7 \| iii-7♭9 - VI7♭9 \| ii-7 - V7 |

## Opprinnelse
Basert på melodi og harmoni fra "I Got Rhythm" av George Gershwin. Progressjonen har blitt standard i jazzrepertoaret og er spilt av kunstnere som Charlie Parker, Miles Davis og Thelonious Monk.
