
# User Investment Habit

User investment refers to the effort, time, data, or content that users contribute to a product. This investment increases switching costs and the psychological likelihood of returning.

## Forms of Investment

- **Content creation** — posts, reviews, playlists
- **Profile setup** — preferences, customization, social connections
- **Streaks and progress** — gamified metrics showing accumulated effort
- **Data contribution** — search history, location data, behavior patterns
- **Commitment devices** — public declarations, paid subscriptions

## The Compounding Effect

Each investment makes the next interaction more valuable. A curated feed becomes more useful as more data is added. A social network becomes more valuable as more connections are established. This compounding is what transforms occasional use into habitual use within the [[hook-model]] framework.

## Connection to Endowment Effect

User investment connects to the [[endowment-effect]] — as users invest more in a product, they value it more highly, increasing perceived switching costs beyond objective measures. This psychological mechanism reinforces the habit loop.
