# Gambler's Fallacy

The gambler's fallacy is the belief that past random events affect future independent events. Each trial is independent, but people expect outcomes to "even out."

## Example
- "Red has come up 5 times, so black is due"
- Believing a stock is "due" for a reversal after a long run

## Mitigation
- Understand that independent events have no memory
- Recognize that probabilities reset each trial
