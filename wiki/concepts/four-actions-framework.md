# Four Actions Framework

The Four Actions Framework is a core analytical tool in Blue Ocean Strategy for systematically rebuilding the value curve. It is a grid-based tool for reconstructing a company's value curve that asks four questions to break the trade-off between differentiation and low cost:

1. **Eliminate** – Which factors that the industry takes for granted should be eliminated?
2. **Reduce** – Which factors should be reduced well below the industry standard?
3. **Raise** – Which factors should be raised well above the industry standard?
4. **Create** – Which factors should be created that the industry has never offered?

By answering these four questions, a company can break away from the existing competitive landscape and create a new value curve that makes competition irrelevant. This framework provides the concrete actions needed to pursue a blue ocean strategy by reconfiguring what the company offers relative to competitors. It is applied after using the Strategy Canvas to identify where the industry overinvests or underinvests, as the strategy canvas analysis reveals where the industry's value curve can be shifted.
