# Model Combination

Integrating insights from multiple models to achieve richer understanding than any single model provides. This is a core methodology in Page's framework.

## Approach

- Identify which aspects of a problem each model illuminates
- Look for convergence across models (where multiple models agree)
- Note divergence (where models conflict, which reveals uncertainty)
- Combine structural insights with probabilistic reasoning
- Use simpler models as sanity checks on complex ones

## Connection to Decision-Making

Model combination parallels [[decision-quality-vs-outcome-quality]] — the process of combining models is analogous to combining diverse perspectives to improve decision quality independent of outcomes.
