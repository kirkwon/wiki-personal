# Depth and Layers

Depth and layers create a three-dimensional feel in a two-dimensional medium, making photographs more immersive and visually rich.

## Creating Depth

| Technique | How | Example |
|-----------|-----|---------|
| Foreground element | Place object close to camera | Tree branch in front of landscape |
| Background element | Include distant elements | Mountains in background |
| Leading lines | Lines create depth | Road receding into distance |
| Aerial perspective | Distant objects less sharp, more blue | Mountains appearing blue and hazy |
| Layers | Multiple planes (foreground, middle, background) | Tree → field → mountains |

## Layering

Three basic layers:
1. **Foreground**: Closest to camera, creates depth
2. **Middle ground**: Main subject
3. **Background**: Sets context, adds depth
