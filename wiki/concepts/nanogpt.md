# nanoGPT

nanoGPT is a minimalist and highly efficient implementation of the GPT architecture, popularized by Andrej Karpathy. It demonstrates how large language models can be trained effectively using minimal resources, often running on consumer hardware. The project serves as an excellent educational tool for understanding the core mechanics of transformer-based generative AI.
