# Pre-Mortem Analysis

Pre-mortem analysis is a structured technique where team members imagine that a project or decision has already failed, then work backward to identify the reasons why. This approach surfaces risks and failure modes before they occur. It asks: "Imagine this decision has failed catastrophically. Why?" This method helps react proactively to possible risk factors before the decision is implemented.

## Method
1. Assume failure (e.g., 1 year later)
2. List all reasons why it failed
3. React to each reason in advance

## Example
Decision: Launch a new product
- Failure reasons:
  - No market need → test the market first
  - Poor execution → hire an experienced team
  - Competitors overtake → continuous improvement
  - Ran out of money → budget for lifecycle
