# Framework Documentation Template

A generic template for documenting frameworks within the wiki. This scaffold provides a standardized structure for capturing key aspects of any framework, including Quick Reference, Overview, Core Components, When/How To Use, Best Practices, Pitfalls, Examples, Advantages/Disadvantages, Related Frameworks, Resources, and References.

This template is intended to be instantiated for specific frameworks rather than serving as content itself. It can be used to document decision-making frameworks, cooking techniques, photography workflows, or any other structured methodology.

## Structure

The template includes the following sections:

- **Quick Reference** — Domain, Purpose, Primary Users, Key Features, Alternatives
- **Overview** — What the framework is and why it exists
- **Core Components** — Breakdown of the framework structure
- **When To Use** — Situations where the framework is appropriate
- **How To Use** — Step-by-step implementation guide
- **Best Practices** — Recommended approaches and tips
- **Common Pitfalls** — Mistakes to avoid
- **Examples** — Real-world implementations
- **Advantages** — Why use the framework
- **Disadvantages** — When NOT to use the framework
- **Related Frameworks** — Comparison to similar approaches
- **Resources** — Documentation, official sites, GitHub, tutorials
- **References** — Papers, blog posts, books

## Usage

When creating a new framework page, copy this template and fill in the placeholder fields with specific content for the target framework.
