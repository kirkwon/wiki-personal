# Markov Models

Models of stochastic processes where the future state depends only on the current state, not on the history of how that state was reached. These capture state transitions and long-run behavior.

## Key Properties

- **Memorylessness**: Only current state matters for next state
- **Transition probabilities**: Fixed probabilities of moving between states
- **Stationary distributions**: Long-run equilibrium frequencies
- **Mixing times**: How quickly the system forgets its starting point

## Applications

- PageRank and web search
- Weather forecasting
- Market regime analysis
- Queueing and resource allocation
