# Network Models

Models of connections and relationships between entities. Network structure profoundly affects behavior — how information flows, how failures cascade, how influence spreads.

## Types Covered

- **Small-world networks**: Highly connected with short path lengths
- **Scale-free networks**: Few highly connected hubs, many sparsely connected nodes
- **Random networks**: Connections formed probabilistically

## Key Findings

- Structure shapes behavior more than individual characteristics
- Hub nodes are critical for system function and vulnerability
- Cascading failures depend on network topology
- Information and contagion spread differently across network types
