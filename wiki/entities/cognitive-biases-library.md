# Cognitive Biases Library

The Cognitive Biases Library is an organized collection of common cognitive biases that influence decision-making in various domains such as cooking (e.g., taste preference bias), photography (e.g., confirmation bias in photo editing), personal finance (e.g., loss aversion and overconfidence effect), and broader cognitive science implications on human behavior. This library serves as a reference for understanding how subconscious thought patterns can lead to systematic errors in judgment across these fields.
