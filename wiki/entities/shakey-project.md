# Shakey Project

The Shakey Project refers to an initiative that combines cooking techniques with photographic documentation to create visually appealing recipes while also exploring the cognitive processes involved in both culinary creativity and image composition. Additionally, it incorporates personal finance strategies by analyzing cost-effective ingredients for budget-friendly yet high-quality dishes.
