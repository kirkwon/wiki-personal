# Nudge

A nudge is an indirect suggestion or cue designed to influence behavior without restricting options; in cooking, it might be a recipe tweak for healthier choices; in photography, using composition techniques to guide viewer focus; in personal finance, default settings that encourage savings; and in cognitive science, subtle prompts that improve decision-making.
