# Everything Is F_cked: A Book About Hope - Mark Manson

Mark Manson's book *Everything Is F_cked: A Book About Hope* explores how human behavior is driven by values, feedback loops, and the faith mechanism. It provides the source perspective for the [[behaviors-mental-model]] mental model.

## Key Themes
- How people construct meaning under uncertainty
- The role of values in shaping behavior
- Feedback loops and their effects on decision-making
- Hope as a navigating principle

This book complements Manson's other work including [[will---mark-manson]], which is already tracked in the wiki.
