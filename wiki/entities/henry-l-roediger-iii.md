# Henry L. Roediger III

Distinguished psychologist and co-author of *Make It Stick*. Roediger III is a leading researcher in human memory and has conducted extensive work on the spacing effect and testing as a learning tool.

## Key Contributions
- Decades of research on the spacing effect—how distributed practice improves retention.
- Co-developed the testing effect paradigm, demonstrating that retrieval practice is a powerful learning strategy.
