# Default effect

The default effect is the tendency to choose an option that is presented as the standard or pre-selected choice in a given context. In cooking, this might mean using ingredients listed first on a recipe; in photography, selecting presets by default; in personal finance, opting for automatic savings plans without actively choosing them; and in cognitive science, it relates to the ease of processing information that is presented as the norm.
