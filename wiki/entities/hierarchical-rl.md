# Hierarchical RL

Hierarchical Reinforcement Learning (HRL) is an approach to reinforcement learning that structures decision-making processes in a hierarchy of policies, where higher-level policies set goals for lower-level ones. This mirrors complex tasks like cooking recipes or photography techniques, which involve breaking down actions into subtasks with clear objectives and sequences. In personal finance and cognitive science, HRL can model how humans plan long-term financial strategies or learn through layered skill acquisition.
