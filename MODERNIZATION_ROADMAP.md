# Modernization Roadmap: Dashboard Pro

## 🎯 Objectives
- **Aesthetic**: High-end SaaS "Modern Dark" aesthetic (Glassmorphism, refined gradients).
- **Stability**: ZERO loss of functionality.
- **Consistency**: Keep the D3 Network Graph exactly as it is.
- **Process**: Step-by-step, reversible, and logged.

## 🛠 Planned Steps

### Phase 1: Foundation & Typography (Visual Polish)
1. [x] **Glassmorphism Base**: Apply backdrop-blur and subtle borders to cards and sidebar.
2. [x] **Typography Hierarchy**: Refine font sizes, weights, and letter-spacing using 'Space Grotesk' for all headers.
3. [x] **Color Palette Refinement**: Transition from solid navys to deep gradients with subtle glowing borders.

### Phase 2: Enhanced Interactivity
4. [x] **Micro-interactions**: Add smooth transitions to all hover states and view switches.
5. [x] **Table Modernization**: Update table styling to match the "card" aesthetic (rounded corners, subtle row highlighting).
6. [x] **Modal Polish**: Re-style the skill detail modal with a glassmorphism overlay and better information density.

### Phase 3: Content & UX
7. [x] **Conflict Guide Upgrade**: Add emojis and icons to the conflict resolution table.
8. [ ] **Responsive Refinement**: Optimize layout for tablet and mobile devices. (Basic responsiveness preserved)

### Phase 4: UX Overhaul (Expertise OS)
9. [x] **Visual Analytics**: Add Category Distribution bar chart to the main dashboard.
10. [x] **Breadcrumbs & Dynamic Headers**: Implement contextual navigation indicators.
11. [x] **Decision Cards**: Transform Conflict Guide table into interactive "VS" cards.
12. [x] **Search Palette**: Enhance search UI to feel like a command palette (Cmd+K).
13. [ ] **Interdisciplinary Markers**: Highlight skills providing high leverage across domains. (Partially addressed via Multi-Tag view)

### Phase 5: Refinement & Interactivity
14. [x] **Tag Filtering**: Clicking any tag badge filters the skills database.
15. [x] **Domain Color Coding**: Assign unique colors to major skill domains for faster recognition.
16. [x] **Data Integrity Check**: Verified overlapping skills count (5) and updated UI to show all data.

### Phase 6: GBrain Integration (Contract-First Knowledge)
17. [ ] **Knowledge Linting**: New '🛡️ OS Health' view to identify orphaned nodes and weak links.
18. [ ] **Traverse Logic**: Add 'Traverse Node' to skill modals to visually shift focus to related clusters.
19. [ ] **Command Interface**: Upgrade Cmd+K palette to support slash commands (e.g., `/source`, `/lint`).
20. [ ] **Compiled Truth**: Refactor skill modals to separate 'Unified Definition' from 'Evidence Timeline'.

### Phase 8: Engagement & Synergy (Proactive Learning)
25. [ ] **Daily Focus**: Dashboard card serving 3 random 'High-Leverage' skills daily.
26. [ ] **Semantic Synergy**: Highlight complementary skills from different sources in the modal.
27. [ ] **Graph Evolution**: Visually distinguish 'Starred' nodes in the Network Graph.
28. [ ] **Decision Journal**: Basic logic to log when a skill is 'deployed' in real life.

## 🛡️ Verification Checklist
- [x] All 8 skins apply cleanly.
- [x] Persistence works across refreshes.
- [x] Slash command menu updated.
- [ ] Daily Focus randomizes correctly based on date.
- [ ] Synergy links show logically related nodes.
