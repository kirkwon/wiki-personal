## New Capabilities vs. Our Existing Skills

### 1. Verification Evidence Ledger (New in v0.18.0)

**What it is**: Profile-scoped record of canonical project checks detected by `agent.coding_context`. Gateway exposes verification status. Pre_verify hook runs custom checks before declaring done.

**What we need to update**:

**`verification-before-completion` skill** — add pre_verify hook pattern:
```python
# v0.18.0: Verification hook runs before "done" is declared
# Configure in profile config.yaml:
#   coding:
#     verification:
#       pre_verify: "python3 scripts/verify.py"
#       stop_loop: true
#       ad_hoc_scripts: true
```

**`software-development-master`** — add completion contracts section. The `/goal completion_contract` feature lets you state what "done" looks like and the agent judges against evidence.

**`skill-governance`** — verify-on-stop is configurable per profile. Our governance should specify verification defaults.

### 2. `/learn` — Distill Skills from Anything (New in v0.18.0)

**What it is**: `/learn <anything>` distills a reusable skill from a directory, URL, or workflow. Honors CONTRIBUTING.md standards. This is a faster path to skill creation than our current `hermes-skill-development-workflow`.

**Impact on our skill creation pipeline**:

| Method | When to Use |
|---|---|
| `/learn` (new) | Quick creation from a directory, URL, or just-performed workflow |
| `skill_manage(action='create')` | Manual full control, complex frontmatter |
| `hermes-skill-development-workflow` (existing) | Multi-step: research → exemplar → create → test → verify |
| `vault-skill-factory` (existing) | Generate from Obsidian vault content |
| Obra `writing-skills` (external) | Create Obra-compatible skills for multi-agent use |

**New workflow**: `/learn` for quick captures → `hermes-skill-development-workflow` for production hardening → `verification-before-completion` for validation.

### 3. `/journey` — Visual Self-Improvement Timeline (New in v0.18.0)

**What it is**: CLI + TUI learning timeline of accumulated memories and skills, with in-place edit/delete. Desktop has a playable radial timeline.

**Impact on `session-logging` skill**: 
- `/journey` replaces some of session-logging's review functions
- Our session-logging should reference `/journey` for visual timeline access
- Memory graph in desktop is a companion, not replacement

### 4. MoA as First-Class Provider (New in v0.18.0)

**What it is**: Named MoA presets show up as selectable models under provider `moa`. Pick any ensemble like any model. All reference model reasoning shown. Live streaming.

**Impact on `dispatch` skill**:
- Add `moa` as a dispatch target for complex reasoning tasks
- Tag: `reasoning`, `deliberation`, `council`
- Best for: architecture decisions, code review, analytical writing

**Updated agent registry entry**:
```
| **moa** (provider: moa) | Complex reasoning, architecture decisions, multi-perspective analysis | `reasoning`, `deliberation`, `council` |
```

### 5. Background Fan-Out for delegate_task (New in v0.18.0)

**What it is**: Parallel subagents run in the background with one consolidated return when all finish. Calm "will resume" affordance. Tracked in CLI + TUI status bar.

**Impact on `delegate-task-protocol` skill**:
- Already supports background dispatch
- Add note about v0.18.0's status bar tracking
- Add note about consolidated return

### 6. Blank Slate Setup Mode (New in v0.18.0)

**What it is**: Minimal agent setup — opt in to everything. Default is opinionated; blank slate lets you build from zero.

**Impact**: Useful for creating minimal profiles for specific tasks. Reference in `hermes-profile-configuration` skill.

### 7. web_extract Changes (New in v0.18.0)

**What it is**: `web_extract` now truncates and stores full text to disk instead of LLM summarization. Concurrent @-reference expansion.

**Impact**: Our `crawl4ai` migration was already the right call. web_extract is now more reliable for large pages. No skill change needed, but note in `web-extraction-backends` skill.

### 8. Friendly Tool Labels (New in v0.18.0)

**What it is**: Human-phrased tool labels for built-in tools.

**Impact**: Our custom skills with `argument-hint` frontmatter are now the standard pattern. No change needed.

## Usage Delta

### How to Use New v0.18.0 Features

```bash
# 1. Quick skill creation
/learn                                    # Distill from current session
/learn ~/projects/my-tool                 # Distill from directory
/learn https://github.com/...             # Distill from URL

# 2. Visual learning timeline  
/journey                                  # See accumulated memories + skills

# 3. Completion contracts for goals
/goal "fix the auth bug" completion_contract="tests pass, no regressions, PR created"

# 4. MoA for complex reasoning
hermes --model moa/my-council             # Select like any model

# 5. Pre-verify hook (in profile config.yaml)
# coding:
#   verification:
#     pre_verify: "python3 scripts/verify.py"
#     stop_loop: true

# 6. Blank slate profile
hermes profile create minimal --blank-slate
```
